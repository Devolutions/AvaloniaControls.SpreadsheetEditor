# Security Policy

## Supported versions

Security fixes are applied to the latest released version of
`Devolutions.AvaloniaControls.SpreadsheetEditor`. Please make sure you are on the most recent release
before reporting an issue.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately by email to:

> security@devolutions.net

Alternatively, use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
if it is enabled for this repository.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce (a minimal sample is ideal).
- The affected version(s).

We will acknowledge your report as soon as possible and keep you informed as we work on a fix. Please
give us a reasonable amount of time to address the issue before any public disclosure.
