# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
CalVer (`yyyy.M.d`). The published version is generated by the CI packaging workflow at release time.

## [Unreleased]

### Added

- Printing: cross-platform PDF export (`ExportPdf`/`SavePdf`), a native Windows print dialog (via
  `PrintDlg` + GDI), and `lpr`/CUPS printing on Linux/macOS. Charts and conditional-formatting data
  bars are rendered into the PDF/print output.
- `.xlsx` save now preserves defined names, merged cells, column widths, conditional-formatting data
  bars, and charts (charts are written as raw OOXML).
- Chart editing: an editable data source (per-series value ranges + categories), support for a series
  spanning several non-adjacent cells/ranges (e.g. `C7, C10`), and category labels that can be entered
  directly or read from a range.

### Changed

- Toolbar icons are now vector paths (previously a Windows-only icon font), so they render on
  Linux/macOS, in a theme-aware shade.

### Fixed

- Editing a chart's settings no longer clears its data.
- A cell's number format (e.g. `$`, `%`) is preserved when editing its value.
- Charts update live when their source cells recalculate.
- Printing on Linux/macOS reports a clear message when `lpr` (CUPS) is missing or fails, instead of
  failing silently.
- The in-cell editor no longer shows a stray scrollbar arrow over the cell content.

## [2026.8.7]

- PDF export/printing, `.xlsx` I/O fidelity improvements, and Excel-compatible number formatting.
  (See the commit history for details.)
